Le notebook est dans le dossier notebooks/. Importez directement ce fichier, sans le télécharger à nouveau. Si un navigateur affiche du JSON, enregistrez-le avec l’extension .ipynb.

03
VOTRE JEU D’ESSAI

Installez le terrain de jeu NovaFlow.

Utilisez le catalogue et le warehouse affichés par le notebook. Choisissez un schéma dédié à votre binôme et l’action installer, puis lancez les cellules suivantes dans l’ordre.

CatalogueExistant et inscriptible
Schémastationf_20261124_votre_equipe
Warehouse IDLes 16 caractères de son ID
Actioninstaller

Vous obtenez trois petites tables : 240 comptes, 48 lignes campagne/semaine et 360 opportunités. Le notebook vérifie six résultats de référence, teste la lecture via votre warehouse et crée votre Genie Agent.

Une erreur ou une installation à relancer ?

Une relance dans le même schéma conserve les données compatibles et les instructions de votre Agent. Le kit refuse d’écraser une table existante incompatible. Le mode revue s’arrête volontairement après le plan, sans rien installer.
